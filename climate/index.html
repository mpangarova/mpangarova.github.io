How much warmer is Bulgaria?

I travel a lot, and I keep noticing how differently the same season feels from place to place. Summers here feel hotter than they used to, but “feels” isn't evidence.

I've always understood things better as a graph than as a sentence. I studied physics, spent ten years in testing and now write Go, so I went looking for the numbers: 75 years of daily measurements for places across Bulgaria. Pick one, enter the year you were born, and see how much its climate has shifted in your lifetime.

    How this page keeps itself honest

    Old habits. I spent ten years breaking software for a living, and the bug that scares me most isn't the crash. It's the number that looks perfectly plausible and is quietly wrong. So I don't trust this page just because the charts look nice.

    Every time it loads, it tests its own data before you see it, right here in your browser:

    The data refreshes on its own, too. Once a month a small Go program, run by GitHub Actions, pulls the latest measurements from Open-Meteo, runs the same checks and only publishes if they pass. If something is off, the page keeps the last good data, and the failing test lands with me, not with you.

    Data and methodology

    Sources: Open-Meteo Historical Weather API (ECMWF ERA5 reanalysis) and the Open-Meteo Climate API (EC-Earth3P-HR, CMIP6 HighResMIP). Daily mean, maximum and minimum temperatures are aggregated by year. Stripes show the anomaly from the 1961–1990 average, the WMO reference period. The model is aligned with the observations using the delta method: its anomaly against its own 1991–2020 mean is added to the observed 1991–2020 mean. Values come from reanalysis grid cells of about 25 km, not from a single weather station, so neighbouring places can look alike.
